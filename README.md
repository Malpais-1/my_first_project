# Мой первый проект на Python

## Что это
Учебный репозиторий. Здесь я учусь программировать на Python. p.s.(бот теперь на sqlite)

## Что внутри
- `hello.py` — первая программа
- `bot.py` — Telegram-бот с заметками

## Как запустить бота
1. Установить Python
2. Установить библиотеки: `pip install pyTelegramBotAPI requests`
3. Вставить свой токен в `bot.py`
4. Запустить: `python bot.py`

## Бот на SQLite
В `bot_sqlite.py` — Telegram-бот с базой данных.

### Команды:
- /start — начать
- /save текст — сохранить заметку
- /list — показать заметки
- /del номер — удалить заметку
- /count — сколько заметок
- /clear — удалить все

### Технологии:
- Python
- telebot
